# SECURITY BASELINE — MUST PASS BEFORE PRODUCTION
Target OWASP ASVS Level 2-appropriate controls. No public financial endpoints without auth. Use established password hashing (Argon2id or suitably configured bcrypt), indistinguishable public reset/login responses, rate-limited recovery and OTP stored hashed, cryptographically random and single-use with expiry. Google login only after verified OIDC state/nonce and secure code flow. Sessions revocable, rotated, HttpOnly Secure SameSite cookie, CSRF/Origin defenses. Deny by default RBAC + organization/object guards; cross-merchant negative tests mandatory.
Secrets: server-only, never in console logs; merchant provider/NRS credentials envelope encrypted, rotated, scoped, masked in UI. Safe validated uploads (signatures/logo/PDF), private storage, content inspection, strict dimensions/MIME/magic bytes; SSRF restrictions. Strict security headers/CSP/HSTS. Exact financial arithmetic, idempotency keys, transactional status changes, event uniqueness, replay handling. Webhook raw-body signatures, independent provider verification where required, amount/currency/reference/merchant checks; redirect never proof of payment.
CI: typecheck, ESLint CLI (not `next lint`), tests, Next build, dependency scan, secret scan, CodeQL, negative authorization and golden doc tests. Secure backup/restore and incident response before production.
